# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - 2025-08-02

### Added
- Form builder interface with drag-and-drop functionality
- Real-time form renderer with live preview
- Field editor for customizing field properties
- Support for multiple field types:
  - Text Field
  - Text Area
  - Number
  - Email
  - Checkbox
  - Select (Dropdown)
  - Radio buttons
  - Datamap
- Field validation capabilities
- Responsive design for mobile compatibility
- Custom CSS styling for form builder interface

### Changed
- Updated React to version 19.1.1
- Updated React DOM to version 19.1.1
- Improved component architecture for better maintainability

### Technical Details
- Built with React functional components and hooks
- Uses Parcel as build tool for fast development
- Modular component structure for easy extension
- CSS-based styling without external UI libraries

### Dependencies
- React ^19.1.1
- React DOM ^19.1.1
- Parcel ^2.15.4 (dev dependency)

## [1.0.0] - Initial Release

- Basic project structure

- Basic form building capabilities
